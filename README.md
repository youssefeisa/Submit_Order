# متابعة الدليفري — PWA Offline

موقع عربي لتسجيل أوردرات الدليفري ومتابعة المحاسبة. يعمل دون backend، ويحفظ البيانات محليًا في المتصفح.

## المميزات
- تسجيل الأوردرات والبحث والتصفية وتسوية الأوردرات.
- تعديل الأوردر مع تسجيل سبب التعديل.
- حفظ محلي ونسخ يومية محلية داخل المتصفح.
- دعم PWA والعمل دون إنترنت بعد فتح الموقع مرة أولى بنجاح.

## تفعيل النشر
من المستودع افتح Settings → Pages، واختر Deploy from a branch، ثم main و /(root) واضغط Save.

## ملاحظات
- لا توجد مزامنة بين الأجهزة؛ البيانات تبقى في المتصفح على الجهاز المستخدم.
- مسح بيانات المتصفح قد يمسح الأوردرات والنسخ الاحتياطية.
- اختبر Offline بعد اكتمال النشر بفتح الموقع أولًا عبر الإنترنت ثم تفعيل وضع الطيران.
